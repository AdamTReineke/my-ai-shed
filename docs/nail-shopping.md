# Nail Shopping Guide

## Nail Type Matrix

| Type | Shank | Coating | Used For |
|------|-------|---------|----------|
| **Common** | Thickest (0.131"–0.162") | Various | All structural connections — framing, sheathing, rim joists. "Common" = the right one when in doubt. |
| **Box** | Thinner than common | Various | Light framing, non-structural. Do NOT substitute for common in structural connections. |
| **Ring-shank** | Same diameter, rings cut into shank | Various | Better withdrawal resistance — subfloor, siding. Rings grip like a screw. |
| **Connector/Hanger** | Varies, short | SS or HDG | Specifically for Simpson ties and hangers. Short (1.5") so they don't blow through. |
| **Metal framing** | Thin (0.113") | Galvanized | For metal connector plates only — NOT a substitute for 8d common. Looks similar, wrong gauge. |
| **Sinker** | Between box and common, vinyl-coated | Plain | Easier to drive by hand. Not the same as common — don't substitute. |

### Coating Guide

| Coating | Abbrev | PT Contact? | Use |
|---------|--------|-------------|-----|
| Bright (plain steel) | — | No | Interior framing only (studs, plates, trusses) |
| Electro-galvanized | EG | No | Interior only — thin coating, ACQ corrodes it |
| Hot-dip galvanized | HDG | Yes | All PT lumber contact, exterior exposure |
| Stainless steel | SS | Yes | PT contact + fiber cement siding (alkaline) |
