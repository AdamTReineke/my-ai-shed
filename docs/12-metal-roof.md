## Panel Layout

Each slope is 216" wide. Each panel covers 36".

- Panels per slope: 216 ÷ 36 = **6 panels**
- Total panels: 6 × 2 = **12 panels**
- Panels run eave-to-ridge (vertically up the slope)
- Start at one gable end, work across; first panel edge set ½" in from gable edge

2. 2" polyiso rigid foam (R-13.1), seams taped
3. 1.5" thick wood purlins (2×4 on flat), 24" o.c., long-screwed through foam into rafters

Metal panels fasten directly to purlins with #10-16 × 1" metal-to-wood sealing screws (brown painted head, Ruspert coated, bonded EPDM washer). Source: Tacoma Screw, Kirkland branch.

### Ridge Closure / Profile Vent — Sourcing Notes

The ridge needs something between the panel ribs and the AR-3 ridge cap to block
wind-driven rain while allowing airflow. Options, in order of preference:

1. **Fabral Shelterguard profile vent** (best fit)
   - Pre-molded foam that exactly matches the Shelterguard rib pattern
   - Look for: "Shelterguard profile vent" or product code "GR3/AT"
   - Sold in 100' rolls (you only need 18' — lots of surplus)
   - Ask at the HD roofing desk or check the Fabral accessories display near the panels
   - If not stocked, Fabral can ship from Salem OR plant: (800)477-9124

2. **Universal foam ridge vent closure** (good substitute)
   - Sold as generic strips, not profile-matched — comes in various rib heights
   - Look for: strips ~1" tall with a porous/perforated foam texture
   - You'd press/trim it to approximate the rib shape with a utility knife
   - Check that the foam is UV-stable (usually polyethylene, not polyurethane)
   - Brands: Quarrix, Air Vent, or HD house brand

3. **AR-3 with RX10 Versavent pre-attached** (alternative ridge cap)
   - Some Fabral distributors sell the AR-3 cap with the vent foam already bonded on
   - This eliminates the separate profile vent purchase entirely
   - Would replace both the AR-3 cap and the profile vent on the shopping list

**How to decide in-store**: If you see foam strips near the Shelterguard panels that have
a corrugated shape matching the panel ribs — that's option 1, buy it. If not, grab a
universal foam closure strip (option 2) and test-fit it against a panel rib in the store.
If neither is available, ask about option 3 or call Fabral.

## Installation Sequence

1. Install CE-1 eave trim on both eaves (screw to eave blocking with #10-16 × 1" sealing screws)
2. Staple 4" insect screen across eave gap (allows airflow, blocks pests)
3. Start first panel at one gable end, ½" in from edge, 1" overhang past eave
4. Secure with #10-16 × 1" sealing screws into purlins per fastening pattern
5. Install gable trim on first panel edge with butyl tape
6. Continue panels across, overlapping 1.75" (overlap edge over underlap edge)
7. Install gable trim on last panel edge
8. Repeat for second slope
9. Mark ridge cap edge on both sides of peak; press profile vent into place ~1" upslope of mark
10. Install AR-3 ridge vent with #10-16 × 2" screws into each panel rib, 1" back from profile vent edge
