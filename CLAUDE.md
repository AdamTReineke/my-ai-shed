# CLAUDE.md

Environment note: You're running on Windows. Node scripts are probably preferred over bash scripts for anything with a little complexity.

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

This is a structural engineering design repository for a 12×16 shed in Redmond, WA. It combines:
- **Node.js calculators** that perform structural analysis (beam sizing, joist sizing, truss analysis)
- **OpenSCAD model** that renders the 3D design
- **Markdown documentation** that records the design decisions and as-built details

There are no build steps, no tests, and no package manager. Just run scripts directly with `node`.

## Running the Calculators

```bash
node joist.js                          # floor joist sizing (default config)
node joist.js --span=108 --live=50    # custom span/load

node beam.js                           # beam sizing (default config)
node beam.js --span=72 --load=800     # custom span/load

node truss.js                          # queen-post truss analysis (default config)
node truss.js --span=12 --pitch=0.5 --snow=20

node footing.js                        # pier/footing sizing
node concrete.js                       # concrete volume calculations

node tools/siding-cuts.js             # HardiePlank cut list
node tools/siding-cuts.js --json      # JSON output
node tools/siding-cuts.js --scad      # also writes model/siding_data.scad
```

## OpenSCAD Model

The model lives in `model/shed_model.scad` and `include`s all the sub-files. Open it directly in OpenSCAD. Visibility of each structural layer is controlled by boolean variables at the top of `shed_model.scad` (e.g. `show_trusses`, `show_siding`).

**Data files generated by Node scripts** (must be regenerated when geometry changes):
```bash
node tools/generate-truss-data.js       # writes model/truss_data.scad
node tools/generate-end-truss-data.js   # writes model/end_truss_data.scad
node tools/siding-cuts.js --scad        # writes model/siding_data.scad
```

## Architecture

### Node.js Calculators

All calculators share `constants.js` which defines:
- `DIM` — shed dimensions in inches (single source of truth)
- `MATERIAL` — Hem-Fir #2 NDS design values with PT incising adjustment factors
- `LUMBER` — section properties (S, I) for each nominal size
- `BEAM_OPTIONS` — pre-computed built-up beam configs via `builtUpBeam()`
- `DEFAULTS` — load assumptions and design criteria

All lengths are in **inches** internally. The `FT = 12` constant is used as a multiplier (`16 * FT = 192"`).

Each calculator (`beam.js`, `joist.js`, `truss.js`, etc.) is standalone: it `require('./constants')`, parses CLI args, runs the structural checks, and prints a results table.

### OpenSCAD Model

`model/dimensions.scad` mirrors the key constants from `constants.js` for use in OpenSCAD. When dimensions change, both files need updating.

The model is split by structural system:
- `foundation.scad` — piers, post bases, beam saddles
- `posts_and_beams.scad` — 6×6 posts and built-up beams
- `joists.scad` — field joists, rim joists, blocking, hurricane ties
- `walls.scad` — stud framing for all four walls
- `wall_cladding.scad` — OSB sheathing, furring, HardiePlank siding
- `trusses.scad` — queen-post trusses (uses generated `truss_data.scad`)

### Documentation

Numbered markdown files in `docs/` document each structural system in order:
`docs/0-readme.md` → `docs/1-piers.md` → `docs/2-beam.md` → ... → `docs/8-fasteners.md`

Also in `docs/`: `lumber.md`, `spans.md`, `checklist.md`, `receipts.csv`.

These are the design record. When a calculator produces a result that changes the design, update the corresponding `.md` file.

## Key Design Parameters

- **Shed**: 16' (E-W) × 12' (N-S), 8' walls
- **Floor system**: 2×10 joists @ 16" o.c., 9' span + 18" cantilevers each end, over two 3-ply built-up beams on 6×6 posts
- **Roof**: Queen-post trusses @ 24" o.c., 6/12 pitch, 1' overhang
- **Wall cladding**: 7/16" OSB + 1×3 furring (rainscreen) + HardiePlank lap siding
- **Location**: Redmond WA — 110 mph wind, 15 psf ground snow, seismic category D
- **Material**: Hem-Fir #2, pressure treated incised where in contact with concrete/ground
